Politique de confidentialité

Votre vie privée est importante pour nous

{% endblock %} {% block content %}

1. Introduction

Kamatera Cloud s'engage à protéger votre vie privée. Cette politique de confidentialité explique comment nous collectons, utilisons, stockons et protégeons vos informations personnelles.

2. Informations que nous collectons

Nous collectons les informations suivantes :

  • Identifiants : Vos identifiants Kamatera pour accéder aux serveurs
  • Données de serveurs : Informations sur vos serveurs (nom, configuration, statut)
  • Journaux d'activité : Actions effectuées dans l'interface
  • Données techniques : Adresse IP, type de navigateur, système d'exploitation
  • Cookies : Données de session pour améliorer votre expérience

3. Comment nous utilisons vos données

Vos informations sont utilisées pour :

  • Fournir et maintenir l'interface
  • Authentifier votre accès aux serveurs
  • Améliorer et optimiser le service
  • Diagnostiquer et résoudre les problèmes
  • Prévenir la fraude et les abus
  • Vous envoyer des notifications importantes

4. Partage des données

Nous ne partageons pas vos informations personnelles avec des tiers, sauf :

  • Avec Kamatera pour accéder à vos serveurs
  • Lorsque requis par la loi
  • Pour protéger nos droits ou votre sécurité
  • Avec des prestataires de services agissant en tant qu'agents

5. Sécurité des données

Nous implémentons des mesures de sécurité techniques et organisationnelles pour protéger vos données :

  • Chiffrement des données en transit (HTTPS)
  • Accès authentifié à l'interface
  • Journaux d'audit des activités
  • Isolation des données utilisateur
  • Mises à jour de sécurité régulières

Cependant, aucun système n'est parfaitement sécurisé. Nous ne pouvons pas garantir une sécurité absolue.

6. Rétention des données

Nous conservons vos données aussi longtemps que nécessaire pour fournir le service. Les données de session sont supprimées après votre déconnexion. Les journaux d'activité sont conservés pour des raisons de sécurité et d'audit.

7. Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Rectifier les données inexactes
  • Supprimer vos données (sous certaines conditions)
  • Vous opposer à certains traitements
  • Obtenir une copie portable de vos données

Pour exercer ces droits, contactez-nous via le formulaire de support.

8. Cookies et technologies similaires

Nous utilisons des cookies pour maintenir votre session et améliorer votre expérience. Vous pouvez contrôler les cookies via les paramètres de votre navigateur.

9. Modifications de cette politique

Nous pouvons modifier cette politique de confidentialité à tout moment. Les modifications seront publiées sur cette page avec une date de mise à jour. L'utilisation continue du service après les modifications constitue votre acceptation.

10. Contact

Pour toute question concernant cette politique de confidentialité ou vos données, veuillez nous contacter via le formulaire de support dans l'application.
